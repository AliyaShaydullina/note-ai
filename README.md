# Note AI

Школьный генератор конспектов на базе OpenAI API.

## Что умеет
- Адаптивная мобильная версия для телефонов и планшетов.
- Тема, предмет и класс.
- Свои ключевые вопросы и слова.
- Генерация подробного конспекта на русском языке.
- Копирование и скачивание результата в TXT.
- Адаптивный интерфейс для телефона и компьютера.

## Запуск
1. Установи Node.js (LTS).
2. Распакуй архив и открой папку проекта в терминале.
3. Выполни `npm install`.
4. Скопируй `.env.example` в `.env`.
5. Вставь свой OpenAI API-ключ в `.env`. Не публикуй этот файл и не отправляй ключ другим.
6. Выполни `npm start`.
7. Открой `http://localhost:3000`.

Для генерации нужен отдельный OpenAI API-ключ и оплаченный API-баланс. Подписка ChatGPT сама по себе не включает API-запросы. Ключ хранится на сервере, а не в браузере.

## Публикация
Для публикации нужен хостинг, поддерживающий Node.js, и настройка переменной окружения `OPENAI_API_KEY` в панели хостинга. Не загружай `.env` в публичный репозиторий.

## Важно
Это стартовая версия проекта. Перед публичным запуском добавь ограничение частоты запросов, лимиты расходов, политику конфиденциальности и защиту от злоупотреблений.
